WASP-12b Photometry & Radial Velocity Analysis
Overview

This repository contains the analysis of the exoplanet WASP-12b using radial velocity and transit light curve methods. The project is divided into two main parts:

Radial Velocity Analysis: Calculation of WASP-12b’s radial velocity using observational data and Bayesian inference methods.

Transit Light Curve Analysis: Modeling of the transit light curve to study the exoplanet’s size, orbital parameters, and relative flux variations.

The goal is to estimate the physical parameters of the exoplanet and understand its orbital behavior.
